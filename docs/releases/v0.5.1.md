# Paranod Addon SDK 0.5.1

The SDK remains MIT. This documentation/package release updates links for the new AGPL-licensed Paranod 2.3.0 application. There are no protocol or runtime API changes from SDK 0.5.0.

Download `paranod-plugin-sdk-0.5.1.tgz` and `SHA256SUMS`, verify the archive, and install it with `npm install ./paranod-plugin-sdk-0.5.1.tgz`. The package includes compiled JavaScript and TypeScript definitions and requires Node.js 22 or newer.

See the [complete polling example](https://github.com/rstlgu/paranod-addon-sdk/tree/v0.5.1/examples/polling-addon) and [platform walkthrough](https://github.com/rstlgu/paranod/blob/v2.3.0/docs/ADDON-WALKTHROUGH.md).
