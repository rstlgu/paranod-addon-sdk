# Paranod Addon SDK 0.5.0

First tagged release of the dedicated MIT-licensed SDK repository. The package import name remains `@paranod/plugin-sdk`.

- Signed, workspace-scoped polling for asynchronous transformations.
- HTTP localhost/LAN platform registration for outbound-only execution, while preserving HTTPS validation for callbacks.
- Encrypted persistent installation and polling-result storage for single-process addons.
- HMAC signatures, timestamps, nonce replay protection and bounded results.
- Complete runnable polling example with explicit secrets and synthetic data.

## Install

Use Node.js 22 or newer. Download `paranod-plugin-sdk-0.5.0.tgz` and `SHA256SUMS`, verify with `sha256sum -c SHA256SUMS` (or `shasum -a 256 -c SHA256SUMS`), then run:

```sh
npm install ./paranod-plugin-sdk-0.5.0.tgz
```

The archive contains compiled JavaScript and TypeScript definitions. No npm registry publication is required. Source and examples are available at this tag. See [the polling example](https://github.com/rstlgu/paranod-addon-sdk/tree/v0.5.0/examples/polling-addon) and [protocol](https://github.com/rstlgu/paranod-addon-sdk/blob/v0.5.0/docs/protocol.md).

Polling is supported by Paranod 2.1 and newer; use Paranod 2.2 for the corresponding graph-agent integration. Existing callback deployments remain compatible. Completed results survive restart when persistent storage and its key are retained; interrupted handlers are not automatically resumed.

Publication is gated on build, lint, tests, dependency audit and package validation. End-to-end investigation through a real AI provider is outside these release checks.
